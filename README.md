# PX League Marketing Website

واجهة تسويقية عربية باتجاه RTL مبنية بـ Next.js App Router وTypeScript وTailwind CSS. لا تحتوي على قاعدة بيانات أو حسابات مستخدمين أو واجهة إدارة أو API خلفي.

## التشغيل

```bash
npm install
npm run dev
```

## الفحص والبناء

```bash
npm run lint
npm run build
npm start
```

## النشر

ارفع المشروع إلى مستودع Git ثم استورده في Vercel. لا توجد متغيرات بيئة مطلوبة للتطوير أو البناء. اضبط `siteConfig.url` في `config/site.ts` على النطاق الرسمي قبل النشر لإكمال canonical وOpen Graph وsitemap.

## الإعدادات

كل القيم التسويقية وروابط المتاجر والتواصل موجودة في `config/site.ts`:

- `googlePlayUrl` و`appStoreUrl`: أضف روابط المتاجر الرسمية؛ الأزرار لا تفتح روابط وهمية عندما تكون القيمة فارغة.
- `supportEmail`: أضف بريد الدعم الرسمي ليظهر رابط `mailto`.
- `socialLinks`: روابط الحسابات الرسمية على Instagram وWhatsApp وX، وتُستخدم في مكوّن الروابط المشترك بالنافبار والقائمة المتنقلة والواجهة والتذييل والشريط العائم.
- `promoVideo` و`promoPoster`: مسار فيديو تعريفي وصورة الغلاف. ضع الملف في `public/video/` ثم حدّث المسار. لا يتم تشغيل فيديو تلقائياً.
- `legal`: أكمل الاسم القانوني والاختصاص وتاريخ التحديث، وراجع نصوص `/privacy` و`/terms` قانونياً قبل النشر.
- `url`: عنوان الموقع الرسمي لتوليد canonical وبيانات SEO وsitemap.

رابطا Google Play وApp Store الرسميان مضبوطان مسبقاً في الإعدادات، وتُعرض شارات المتاجر الرسمية في الصفحة الرئيسية والتذييل. تتطلب Apple استخدام الشارة الرسمية دون تعديلها؛ ملفات الشارات محملة من خدمات العلامة التجارية الرسمية للمتجر.

## AdMob app-ads.txt

الملف العام موجود في `public/app-ads.txt` وسيُنشر على مسار الموقع الجذري `/app-ads.txt`. أضف سطر الناشر الدقيق من حساب AdMob إلى الملف قبل طلب التحقق؛ لا تضف معرفاً تخمينياً. كذلك اضبط `siteConfig.url` على النطاق الرسمي وأضف رابط الموقع نفسه إلى حقلي موقع المطوّر في Google Play وApp Store حتى تتمكن AdMob من ربط التطبيق بالموقع.

## الصور والمحتوى

- صور الهوية المعاد استخدامها في `public/brand/`.
- ضع لقطات التطبيق الأصلية في `public/screenshots/` ثم حدّث قسم الصور داخل `components/sections/home-sections.tsx`. لم تتوفر لقطات شاشة من المشروع المرجعي وقت البناء؛ بطاقات القسم الحالية توضيحية وليست صوراً للشاشة أو بيانات فعلية.
- الخطوط المعاد استخدامها في `public/fonts/`.
- نصوص الصفحة الرئيسية والأسئلة الشائعة موجودة في `components/sections/home-sections.tsx`.
- يمكن تعديل ألوان الموقع من متغيرات CSS أعلى `app/globals.css` وإعدادات الهوية في `config/site.ts`.

## أصول الهوية

نُسخت الأصول من مشروع PX League المرجعي للقراءة فقط: `assets/icons/final-app-icon.png`, `assets/icons/app_icon.png`, `assets/fonts/Cairo-Regular.ttf`, و`assets/fonts/Cairo-Bold.ttf`. لم يُنسخ أي ملف إلى المشروع المرجعي أو يُعدّل فيه. لم يُعثر على لقطات تطبيق أو فيديو ترويجي مناسب ضمن أصول المصدر.
